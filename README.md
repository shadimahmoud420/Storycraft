# StoryCraft

تطبيق Flutter واحد يعمل على **Android و iOS** لتصميم قصص إنستغرام:

- **الخلفية:** صورة من المعرض، أو لون كلاسيكي، أو تدرج لوني جاهز أو مخصص مع التحكم في اتجاهه.
- **النصوص:** 80 خطاً (43 عربياً مصنفة: عصري، كوفي، نسخ، مخطوط، عناوين، و37 إنجليزياً)، مع تعبئة **ذهبية وفضية ووردية ومتدرجة**، و**حدود للحروف**، وتباعد الحروف والأسطر، و**نص منحني** يحافظ على اتصال الحروف العربية.
- **فلاتر للصور** (حيوي، دافئ، بارد، قديم، أبيض وأسود، باهت، درامي، وردي) بشدة قابلة للتعديل.
- **مقاسات متعددة:** قصة 9:16، منشور 4:5، مربع 1:1، عريض 16:9.
- **ألوان طبيعية:** توازن أبيض وإضاءة وتباين تلقائي بضغطة زر.
- **تحسين ذكي:** رفع دقة الصور الصغيرة حتى الضعف، مع زيادة الحدة (مع حماية من إبراز التشويش) والوضوح المحلي. كل ذلك يعمل على الجهاز، مجاناً وبدون إنترنت.
- **التصدير:** صورة بمقاس 1080×1920 تُشارك مباشرة في قصة إنستغرام، أو تُحفظ في الصور، أو تُشارك عبر أي تطبيق.
- **اللغة:** واجهة عربية (من اليمين لليسار) وإنجليزية، مع الوضع الليلي.
- **قوالب جاهزة:** 12 تصميماً لرمضان والعيد والجمعة وصباح الخير والتهاني والتخرج.
- **عبارات جاهزة:** أذكار، صباحيات، حكم، تحفيز، وعبارات إنجليزية.
- **ملصقات:** إيموجي ورموز وأشكال (إطارات، خطوط، ملصق خلفية للنص).
- **تراجع وإعادة** لكل خطوة، و**مسودات** تُحفظ تلقائياً في الجهاز.
- **تحريك الصورة وتكبيرها** داخل القصة، و**تعتيم** الصورة، و**خلفية زجاجية** خلف النص لسهولة القراءة.
- **خطوط إرشاد للمنطقة الآمنة** (أعلى القصة وأسفلها) مع مغناطيس للمنتصف أثناء السحب.
- **هويتي التجارية:** الشعار وألوان الهوية والخط المفضل في كل تصميم.
- **يعمل بالكامل بدون إنترنت:** الخطوط والرسومات مضمّنة في التطبيق.
- **الشاشات:** لوحة التصميم ثابتة (360×640) وتتكيّف مع حجم كل شاشة، فيظهر التصميم نفسه على أي جوال.

## البدء السريع
```bash
ORG=com.yourname bash tool/setup.sh   # مرة واحدة
flutter run
```

## بنية المشروع
```
lib/
  main.dart, app.dart          نقطة البداية، الثيم، اللغات
  core/                        الإعدادات، النصوص AR/EN، الثيم
  data/                        الخطوط والألوان والتدرجات
  models/                      الخلفية وطبقات النص
  state/editor_controller.dart حالة المحرر
  services/
    image_processing.dart      ألوان طبيعية + تحسين ذكي (في Isolate)
    story_exporter.dart        تصدير 1080×1920 + مشاركة + حفظ
  screens/                     الرئيسية والمحرر
  widgets/                     لوحة التصميم، محرر النص، الخلفيات، منتقي الألوان
packages/instagram_story_share إضافة أصلية (Java/Swift) للمشاركة المباشرة في القصة
tool/                          سكربتات الإعداد والأيقونة
```

## إعدادات يجب تعديلها
- `lib/core/config.dart`: قيمة `facebookAppId` (مطلوبة للمشاركة المباشرة في إنستغرام)، وقيمة `privacyPolicyUrl`.
- `ORG` عند تشغيل سكربت الإعداد، و `bundle_identifier` في ملف `codemagic.yaml`.
- البريد الإلكتروني في `docs/privacy-policy.html`.

## تطويرات مقترحة لاحقاً
- تضمين الخطوط داخل التطبيق (assets) ليعمل كلياً بدون إنترنت من أول تشغيل.
- التقاط صورة بالكاميرا، وملصقات، وقوالب جاهزة.
- تحسين بالذكاء الاصطناعي عبر خادم (مثل Real-ESRGAN)، كميزة مدفوعة اختيارية.
